Для действующих кладовщиков распределительного центра сети «У Михалыча» (Тимуровцев, 1А стр. 8).

## Пройти онлайн

**https://arimberg-svg.github.io/rc-kladovshchik-test/**

Перед стартом: **имя, фамилия, должность**.  
После прохождения полный отчёт уходит на **arimberg@gmail.com** сразу по двум каналам.

Порядок вопросов каждый раз другой — списывать с соседа бесполезно.

## Норма

**20 из 25.**

Ошибка в вопросах на **честность** (излишек, факт в ордере, хищение) — красный флаг даже при зачёте. Его видно на экране и в письме.
